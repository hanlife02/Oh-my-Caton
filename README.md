# ⬡ Oh my Caton

面向 **Board Game Arena（BGA）卡坦岛**的 Chrome / Edge Manifest V3 扩展，在**游戏进行中实时追踪**玩家资源，支持基础版及城市与骑士的常见资源事件。对局内的新日志到达后自动更新右下角面板，无需刷新或等待游戏结束。无需构建，无运行时依赖，无服务器。

项目地址：https://github.com/hanlife02/Oh-my-Caton

## 安装

1. 下载本仓库并解压，或克隆到本地。
2. 打开 `chrome://extensions`（Edge 使用 `edge://extensions`），开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择含有 `manifest.json` 的项目根目录。
4. 刷新 BGA 卡坦岛对局页面，例如 `https://boardgamearena.com/tableview?table=123456`。扩展会在实际承载游戏的 iframe 内启动。
5. 面板出现在右下角。点扩展图标可显示或隐藏。

建议在初始放置前启用，并保持对局标签打开。生产、建造、交易和偷牌发生后面板自动更新。中途加入且看不到开局日志时，先校正对手当前手牌，再继续实时跟踪。

若使用打包生成的 ZIP，请先解压，再加载解压后的目录。无需加载 `node_modules`。

## 功能与使用

- 追踪木材、砖块、羊毛、麦子、矿石、纸、布、金币和未知牌。
- 资源合计后显示已建村庄数、城市数、贸易／政治／科学改良等级及公开得分。直接跟随页面的公开玩家计数器更新；资源待校正时，这些公开统计仍正常显示，缺少数据时显示「—」。
- 解析资源获得/失去、弃牌、道路/村庄/城市/发展卡购买、银行交易、玩家交易、偷牌。
- 城市与骑士：商品生产与交易、骑士招募/升级/激活、城墙、按等级扣除城市改良费用、起重机折扣、灌溉/引水渠、强制交易及有可见明细的垄断/联姻/大商家。建造优先使用日志中明确打印的实际费用。
- 中英文常见日志，保留包含空格的完整玩家名。
- 拖动标题栏移动，支持折叠/隐藏面板；默认只显示对手的资源。
- 标题同行可输入背景透明度百分比（0–100）：0% 不透明，100% 完全透明，默认 15%。输入后即时生效并本地保存，文字和图标保持清晰。
- 点击玩家旁的 `✎`，设置该玩家当前全部手牌，包括未知数量。校正会随本桌保存。
- 使用 `data-move-id`、包含资源图标的原始日志签名和同回合出现次数匹配已见日志；页面内按 DOM 日志编号排序，跨刷新不依赖会重置的 `log_N`。私有明细补全公开转移时更新原事件，不重复记账；刷新不丢失已揭示的牌型。
- 有回合标识的已见日志按桌号保存到 `chrome.storage.local`，刷新后匹配恢复；缺少回合标识的日志只在本页追踪。同回合重复日志窗口不完整时会提示匹配不确定，需校正。
- 资源不足时整条事件保持原子性，避免部分扣牌或负数。

### 数字是什么意思

日志完整且没有待校正提示时，每种资源的数字表示**确定持有的最低数量**，`❓` 是牌型不确定的剩余手牌，合计是追踪到的总牌数。出现资源不足、回滚或转移数量不可见提示后，相关玩家显示「待校正」和破折号，停止展示失效的资源数与合计。

例如 Alice 有 2 木材、1 矿石，Bob 偷走一张但牌型不可见：Alice 显示至少 1 木材和 1 未知，Bob 增加 1 未知。若 Alice 只有一种确定资源且无未知牌，可推断被偷牌型。此方式保守记录，不枚举所有可能手牌。

### 适用范围与限制

- 建议从开局前启用。插件只读取页面可见 DOM，不访问隐藏牌、游戏内部对象或未公开数据。
- **尚未读取的旧日志无法凭空恢复**。中途安装或加入时，加载页面历史日志，或用 `✎` 先校正当前手牌。保存历史不等于自动向 BGA 拉取完整历史。
- 初始放置/免费道路依赖日志中的「免费」「初始」「placed」「free」「road building」标记。若 BGA 日志未说明免费，可能误扣，请用手动校正修正。
- 基础版常见中英文日志及实测的城市与骑士中文日志受支持，未见过的日志变体仍可能需要适配。联姻按规则转移 2 张，不足时转移剩余手牌；不可见的牌型记为未知。其他无法确定数量的垄断/大商家转移会提示校正。撤销目标及其后续动作仍在可见日志中时，会撤回整段资源变化，并区分撤销后重做的动作。撤销范围无法确定时，标记操作者及本回合已观察到的交易/偷牌伙伴，提示校正。
- 已在 Dia 验证真实对局 iframe 内自动启动与刷新恢复。另将一桌城市与骑士的完整官方可见日志脱敏、转换为游戏 DOM 格式，从空手重放第 1–353 步：自己的终局结果为 **2 木材、3 砖块、2 纸，共 7 张**，与独立终局盘面一致；刷新为末尾日志窗口后仍一致。这不等于所有玩家、所有事件的整局准确性通过，回滚及隐藏转移仍会显示待校正提示。
- v0.2.0 更换了解析规则存档标识：旧版存档原样保留，不再与新版事件混算。升级后请从开局开始追踪，或先校正当前手牌。
- v0.2.1 修复日志稍后补充回合编号时的保存与去重，以及间谍偷取发展卡被误算为资源转移的问题。
- v0.2.2 修复联姻转移被跳过、破坏者等卡牌前缀导致资源动作漏算的问题，并从已保存的标准化日志恢复旧版漏算的获得/丢弃事件。真实进行中对局第 321 步的 648 条存档已加入回归测试，独立截图为 **3 砖、1 矿、4 纸，共 8 张**，旧版误报 13 张。另修复末尾无回合编号的信息日志导致校正无法保存；待校正行不再显示失效数字。这不代表所有玩家、所有事件的整局准确性通过。
- v0.2.2 同时修复普通 `⇌` 玩家交易漏算、待校正玩家的旧牌型污染偷牌推断、回滚误标全部玩家和重复提示。延迟获得回合编号、以及私有通知随后与公开转移合并时的手动校正均可持久保存。扩展重载导致旧页面上下文失效时会停止监听并提示刷新，不再抛出未捕获异常；临时保存失败可在恢复后清除提示。当前 72 项自动化测试通过，新局实时验证另行进行。
- v0.2.3 修复外交官在同一步、没有资源动作时被取消仍触发手牌失效的误报；涉及资源动作或无法识别的资源文本时仍保留校正提示。
- v0.2.4 支持按通知顺序识别完整撤销片段，恢复被撤销的建造与交易等资源变化；重用回合编号的重做动作独立记账，刷新后不会让旧动作恢复生效。旧分支内的手动校正及私有明细也不再影响当前手牌。面板更紧凑，资源图标更大，玩家名跟随游戏颜色，默认隐藏自己，并移除了辅助操作和常驻说明文字。
- v0.2.5 修复未提交资源动作的空撤销仍导致待校正的问题；要求看到紧邻的前一步通知及同一步取消确认，历史不完整时保留提示。
- v0.3.0 在资源后增加村庄、城市、贸易／政治／科学等级及公开得分六列，随页面公开计数器实时更新，支持建造和撤销后的同步；保留紧凑布局、大图标、玩家颜色和默认隐藏自己，面板背景调整为轻微半透明。
- v0.4.0 在标题栏增加紧凑的透明度百分比输入框，即时调整并保存，刷新后恢复；调整时不会触发面板拖动。
- v0.4.1 将撤销判断移到完整的本地通知序列，保存跨刷新顺序和通知来源；支持从无资源动作（例如药物、锻冶匠）开始撤销、目标离开页面后的恢复、重复撤销至同一检查点以及相同动作重做。升级会校验并修复可证实的旧分支，不再重复扣除旧城市费用；历史无法确定时保留校正提示。
- 暂不支持同一桌多个标签页同时写入存档，也不支持在 BGA 回放中切换历史时点。
- 本地存档不会自动清理；清除扩展数据或卸载扩展会丢失。无遥测，不上传日志。

## 开发与验证

Node.js 22+、Python 3（仅打包需要）。

```sh
npm ci
npm test
npm run check
npm run package
```

产物位于 `dist/Oh-my-Caton-0.4.1.zip`。`jsdom` 只用于测试，不打入扩展。

```text
manifest.json       扩展入口和权限
src/engine.js       资源计算与原子事件结算
src/parser.js       BGA DOM 日志解析
src/journal.js      回合日志匹配、排序与偷牌揭示合并
src/panel.js        Shadow DOM 悬浮面板
src/content.js      日志监听、按桌存储、校正及重放
src/popup.*         扩展图标弹窗
scripts/package.py  生成可加载 ZIP
test/               引擎、解析器和页面集成测试
```

测试覆盖资源成本、未知偷牌、私有明细去重与晚到/刷新、交易原子性、城市改良折扣、双方校正、完整真实日志重放、刷新日志窗口、重复节点、延迟加载容器等。真实日志夹具来源与转换说明见 [test/fixtures/README.md](test/fixtures/README.md)。
